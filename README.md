# Age Calculator using Python

## 📌 Project Overview
The Age Calculator is a simple Python project that calculates a person's age based on their date of birth. It uses Python's `datetime` module to calculate the age in years, months, and days.

## 🚀 Features
- Accepts the user's date of birth as input.
- Calculates age based on the current date.
- Displays age in years, months, and days.
- Uses Python's built-in `datetime` module.
- Beginner-friendly project for learning Python programming.

## 🛠️ Technologies Used
- Python
- Datetime Module

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   `python age_calculator.py`

4. Enter your date of birth when prompted.
5. View your calculated age.

## 🎯 Learning Outcomes
This project demonstrates basic Python programming concepts, user input handling, date manipulation, conditional logic, and calculations.
